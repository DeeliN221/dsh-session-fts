# 会话全文搜索

按内容搜索本机上的所有历史会话。

- **纯本地。** 派生的 SQLite FTS5 索引保存在 `~/.dsh/session-fts.sqlite`，数据不离开本机。删除该文件后，插件会从会话日志重新建索引。
- **中文可用。** 每个中日韩字符单独作为一个词元入库，查询按连续字符匹配，所以 `全文搜索` 能命中句子中间的字面子串。英文按单词和前缀匹配（`sqlite` 也能找到 `sqlite3`）。
- **时间范围。** 今天、近 7 / 30 / 90 天、全部或自定义日期，默认近 30 天。
- **筛选。** 工作区、发言方（我 / 助手 / 工具输出）、是否包含子代理会话，按相关度或时间排序。
- **智能体工具。** `session_fts_search` 默认只搜当前工作区（`scope: "all"` 搜全部），并跳过当前会话。

从左侧栏的 **会话搜索** 打开。点击结果会打开对应会话。

## 配置

| 字段 | 默认值 | 含义 |
|---|---|---|
| `path` | `~/.dsh/session-fts.sqlite` | 索引的绝对路径 |
| `indexToolOutput` | `false` | 同时索引工具调用与结果（更大、更杂） |
| `defaultDays` | `30` | 智能体工具未指定日期时的范围，`0` 为全部 |
| `maxResults` | `20` | 每页会话数 |
| `maxDocChars` | `20000` | 每条消息最多索引的字符数 |
| `includeSubagents` | `false` | 默认是否包含子代理会话 |

修改 `indexToolOutput` 或 `maxDocChars` 会重建索引。

## 限制

- 点击结果打开会话，不定位到具体消息。
- 用户消息只索引本人输入的内容，注入的上下文（技能目录、运行时上下文等）会跳过；推理过程不索引。
