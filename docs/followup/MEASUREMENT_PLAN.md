# 第二轮验收与测量计划

固定于 2026-11-20，任何第二轮性能测量之前。首轮报告、包、证据、SHA256SUMS 不改写。

## 原生入口

只读确认 NAS 原生工具注册、sessionQuery 提供者、sessionPersistence 与搜索启用配置。SDK 复现使用隔离数据库；生产档案只做只读元数据列举或只读句柄观察，不迁移或保存。定位已观察错误的实际 cause；若需要核心修改，只交独立补丁及可复跑验证，不改安装 runtime。自定义 FTS 搜索成功不算原生工具修复。

## 两台物理设备

Mac 与 NAS 各自运行真实 Cordis、AgentLoop、JSONL persistence、FTS 和 memory 插件；模型使用确定性 fixture，不调用付费 API。每端独立根与 SQLite 文件。中央端仅绑定 NAS 127.0.0.1 随机端口，通过本轮受控 SSH 转发让 Mac 访问；测试结束关闭进程与转发。记录设备 hostname、runtime、原生 session/seq、自动引用与人工本地 HTTP 搜索的相同 evidenceId。

边界矩阵：同用户跨设备；另一用户；相同 sessionId/seq 的设备冲突；同名工作区无映射拒绝、显式映射授权；当前会话排除；中央断连只查本地；鉴权失败不回退；重连后幂等索引与重复召回抑制；已注入引用不递归进入中央。未覆盖来源保留。

## 性能

词法固定语料：100 个会话，每会话 20 个中英混合文档，共 2000 文档；32 个交替查询词（英文与中文各半），预热每词一次。单并发每条测量路径每种语言至少 1000 次有效请求；保存每次样本，以 nearest-rank 计算 p50/p95/p99，拒绝把首轮 20 次中位数称为生产分位。回包必须校验命中，失败样本单列，不混入成功分位。

分别测量本地统一检索包装、人工 HTTP 全文入口、跨设备中央 HTTP 统一检索（包含 SSH 转发实际网络传输和 JSON 包装）。本地热 p95 <= 100ms 为目标，不是生产承诺。冷启动/首个词法请求独立至少 5 个进程；不强制清 OS 页缓存，因此称进程冷启动。语义首载至少单独 1 次真实离线模型推理，记录同时到来的词法请求延迟；不把模型下载计入加载。索引增量与空闲 CPU/heap 沿用首轮口径并明确样本时窗。NAS 只运行小型第二端 fixture 与中央端，较重索引/测量在 Mac。

## 停止线

不足样本、第二端不可达、真实浏览器/正式登录未测均写 not-run 或具体缺口；不重启现有 worker。只重跑本轮新增或变更影响的测试。最终产出 FOLLOWUP_REPORT.md、followup/acceptance.json、原始日志/样本、分支提交、候选包及校验摘要、NAS 最小接入草案和无损回滚。
