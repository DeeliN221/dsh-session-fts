# 0.3 搜索限制改进验收

## 变更范围

会话标题继续打开会话；每条片段可单独点击，通过持久事件 seq 定位用户、助手最终回复和工具消息。定位有页面数与时间预算，等待其他读者已启动的分页，取消时释放引用和订阅。折叠展开后等待可见及稳定几何，再滚动、聚焦并验证目标位于会话视口；不按片段文本猜测位置。当前没有 Chat 视图时明确报告，不能跨视图伪报定位成功。

SQLite 打开、写入、全文与标题查询、状态统计和关闭均在专属 worker。主插件已实际接入异步 API，不仅增加独立测例。HTTP 断开后取消排队的词法请求；已经执行的同步语句仍运行至结束，但不会阻塞 Host，且占用原队列槽防止无限排队。

同机共享本地 SQLite 的初始化和写入使用 BEGIN IMMEDIATE，revision 持久化；查询缓存以同一读事务观察到的全局 revision 验证。不同 sourceId、模式或提取配置拒绝共享，不自动清库。一次进程局部列表不会删除其他进程的 live-only 会话；对持久会话的清理还需成功的 persistence listing 与即时 stat 复核。

## 测试与测量

词法测试启动真实子进程覆盖同时创建数据库、重复写入、缓存跨进程失效、清空后重读、配置冲突保留数据、写入中 SIGKILL 的事务原子性、worker 退出、请求取消、超时、队列上限和关闭。插件测试通过真实 AsyncFtsStore 驱动实际 apply/tool 注册，覆盖 async 接入和局部列表误删保护。

导航测试覆盖冷历史多页、助手 anchor 与最终事件 seq 不同、工具事件身份、重复点击旧响应、目标删除、取消与释放、共享分页进行中、折叠展开动画、几何稳定、滚动后视口验证及预算耗尽。使用固定测试模型的语义测试仍操作真实 sqlite-vec。

Node v26.6.0 / macOS arm64 的固定合成语料为6,000条消息，重复20次。一次完整测试的同步路径总计183ms、最大计时器延迟182ms；worker路径总计178ms、最大计时器延迟1ms且期间有79次计时器运行。同步路径是受控负例；此测量验证隔离 Host 阻塞，不声称 SQLite 计算本身加速，也不代表浏览器端到端延迟。命令 `node --test tests/lexical.perf.test.js`。

## 分布式范围

[分布式方案](DISTRIBUTED-SEARCH.md) 是待审核部署设计，尚未修改 NAS 服务或启用跨设备同步。建议 NAS 统一搜索 API/鉴权/持久化，worker 增量 outbox 同步并计算批量文档向量，查询模型在 NAS 常驻，避免依赖休眠设备；使用用户、设备、profile、sessionId、seq 复合身份和模型 hash，明确删除 tombstone 与 ACK 水位。现有中央服务只有 turnIndex，需补精确 seq 等协议后再复用，不能直接称为已具备全局消息定位。

## 完成后的实际证据

`pnpm test` 最终35个顶层用例全部通过；语义入口内另驱动6个集成场景，包含真实 OS 进程同时刷新、首次 follower 只读打开、写者 SIGKILL 后租约恢复、旧写者 fencing、模型冲突保留数据。`pnpm run check` 通过。真实 multilingual-e5-small q8 CPU 模型再次通过中英跨语言召回。最后完整测试的 worker计时器最大延迟仍为1ms，对照同步路径为182ms；原始诊断输出保留在测试运行记录。

候选 `0.3.0-zzl.1` 已通过标准插件安装到 Mac 现有 https://mac.xbugs.site/，未替换服务器或重启 DSH。实际状态接口返回全文索引 idle、无错误，语义后台正常刷新。浏览器点击全文片段后成功定位助手最终事件 seq，并验证聚焦元素带精确 Chat node key 且可见；当前运行中的长会话也未落到相邻消息。历史会话中可见先前 HTTP413 错误日志，不代表本次模型调用再次失败，本轮实际工具调用持续成功。
